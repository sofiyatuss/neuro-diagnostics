# NeuroNook V2

A standalone educational pixel-clinic browser game.

## GitHub Pages
1. Create a **public** GitHub repository named `neuronook`.
2. Upload `index.html` to the repository root and commit.
3. Open **Settings > Pages**; under **Build and deployment**, select **Deploy from a branch**, branch **main**, folder **/(root)**; save.
4. Visit `https://YOUR-USERNAME.github.io/neuronook/` once Pages reports deployment.

Clinical cases are fictional educational composites. Visualizations are synthetic.
